# Junk-Fusion音乐播放器项目

这是一个以juce做UI和音频引擎，FFmpeg做编码层，onnx runtime做AI推理层，spdlog做日志分析的音乐播放器项目，flutter作为前端UI

## 软件工程规范

1. 完成任务后不要自行build
2. 进行架构调整的时候建议看一下我的git记录
3. 我没叫你做的事情决定禁止做，你可以向我提议，但是禁止亲自做
4.  不要把我写的注释给删了，就算那段注释看起来没有用
5.  对我的问题有任何疑问请直接告诉我，不要自我猜测和不说出来就直接写代码
6.  业务bug和性能bug(应用崩溃，空指针，白屏)的危险等级同样高，禁止为了解决性能bug引入业务bug
7.  我的问题有两个前缀:[提问]和[任务]：当在[提问]前提下，只回答我的问题，不要修改任何代码。当在[任务]前提下，可以修改代码。当我忘记加上这个前缀词的时候，请默认使用[提问]模式，并告诉我应该加上前缀词
